廃棄率管理アプリ Ver.1（試作）

【使い方】
1. index.html をブラウザで開くと動きます。
2. 「入力」で日商・実廃棄を入力すると、ホーム・カレンダー・分析が連動します。
3. データはブラウザの localStorage（端末内）に保存されます。
4. 「設定」から店舗名・対象年月・目標廃棄率・繰越・臨休日を変更できます。

【iPhoneでホーム画面追加したい場合】
PWAとしてホーム画面追加するには、HTTPS上で公開する必要があります。
GitHubは必須ではありません。Vercel / Netlify / Cloudflare Pages等へアップロードして公開できます。
（試作確認だけなら index.html のままでOKです。）

【Numbers版から引き継いだ主な考え方】
・累計売上 = 営業日の入力済み日商合計
・累計廃棄 = 営業日の入力済み廃棄合計
・現在廃棄率 = 累計廃棄 / 累計売上
・日商平均 = 累計売上 / 入力済み営業日数
・月末売上予測 = 日商平均 × 月間営業日数
・月末廃棄上限 = 月末売上予測 × 目標廃棄率
・残り廃棄可能 = 月末廃棄上限 - 累計廃棄
・1日廃棄目安 = 残り廃棄可能 / 残り営業日
・休業日はNumbers版に合わせ、土日・祝日（2026〜2030対応）・臨休日を除外

※ Ver.1は端末内保存のため、別端末との同期・ログイン・バックアップはまだありません。
